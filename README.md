# ForgeKiln

ForgeKiln is an experimental C++ project by Cedric Arts, currently focused on learning and building the foundations of a game-development engine and its supporting systems.

The project is in an early stage. APIs, architecture, and project structure may change as development progresses.

## Project status

**Early development.** This repository is a work in progress and is not yet intended for production use.

Current experiments include:
- Keyboard input handling in C++.
- Small, focused systems that can later become part of a larger engine.

## Getting started

### Requirements

- Windows
- A C++ compiler with Windows SDK support, such as MSVC
- Git (optional, for cloning the repository)

### Build and run

Build instructions will be added as the project gains a stable build system. For now, open the source files in your preferred C++ IDE and compile them with a Windows-compatible compiler.

## Development principles

- **Understand the implementation:** prefer learning and maintainable code over blindly copying solutions.
- **Keep it simple:** build small systems before adding abstractions.
- **Iterate:** expect early designs to change as the project develops.
